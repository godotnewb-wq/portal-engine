# engine/core

Small things every system uses: content ids, seeded dice, name matching, and the `Prompt` shape.

**Public API** (`@engine/core`): `IdSchema`; `dice(state)` (resumable seeded dice), `seedFrom`, `draws`, `seedOf`; `plainName`, `namesCharacter`, `resolveName`, `firstName`; `Prompt`.

**Depends on:** nothing.
